# 🐍 Snake Game using Pygame

A classic Snake Game built using Python and Pygame, demonstrating game loop design, collision detection, and event handling.


## 🎮 Features
- Smooth keyboard controls (Arrow keys)
- Real-time score tracking
- Random food spawning
- Wall collision detection
- Self-collision detection
- Game over screen with restart option


## 🛠 Tech Stack
- Python
- Pygame


## 🚀 How to Run
### 1️⃣ Clone the repository
```bash
git clone https://github.com/Akansha-08/Snake-Game-Pygame.git
cd Snake-Game-Pygame
```

### 2️⃣ Install dependencies
```bash
pip install pygame
```

### 3️⃣ Run the game
```bash
python snake.py
```


## 🎯 Controls

- ⬅ Left Arrow → Move Left
- ➡ Right Arrow → Move Right
- ⬆ Up Arrow → Move Up
- ⬇ Down Arrow → Move Down
- P → Play Again (after Game Over)
- Q → Quit Game
